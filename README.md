# Filingo Official Website

This is the official website for the Filingo iOS app, showcasing app features, privacy policy, and terms of service.

## Website Structure

- `index.html` – Home page, presenting app features and highlights
- `privacy.html` – Privacy policy page
- `terms.html` – Terms of service page
- `assets/css/style.css` – Shared stylesheet
- `assets/images/` – Image assets directory (to be added)
- `assets/js/` – JavaScript assets directory (to be added)

## Features

- Responsive design for mobile and desktop
- English interface targeting international users
- Clear navigation structure
- Content suitable for Apple App Store presentation

## Development Notes

The site is built with plain HTML5 and CSS3, requiring no build tools or frameworks.
All pages share the same stylesheet for visual consistency.
